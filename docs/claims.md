# First Light Hunt claims

From dawn pastoral photographs and the style lock, written before the loop.

1. **Electric meadow.** Sunlit grass is saturated green, not mint pastel.
2. **Blue distance.** Ridges recede through blue-grey haze, not peach cones.
3. **Hard sun.** Shade is cooler and darker; the horse throws a long ground shadow.
4. **Dark hero.** The horse is a dark readable silhouette against the grass.

A metric that scores a bald green plane equal to a dressed meadow is rejected.
